# НУШ у Mihko — пілот 0.1

Окрема статична сторінка НУШ для GitHub Pages з картою розвитку курсів 1–4 класів та **24 оригінальними картками 1 класу**: по 6 для математики, української мови, англійської та ЯДС.

Це авторський каталог для перевірки. Він не є повною освітньою програмою, не пройшов методичне затвердження і не підключений до Android. Файл `pilot.json` не є форматом `game3d/data/course.json`.

## Перегляд і публікація

- Адреса окремого публічного сайту: https://neurolutionary.github.io/mihko-nush/nush/
- Збірка: `node tools/nush/build.cjs`.
- Перевірка: `node --test tests/nush.test.cjs`.
- Відкрити через локальний HTTP-сервер каталог `dist/nush-pages` (JSON завантажується через fetch).
- Workflow **Mihko NUSH checks** живе в окремому публічному репозиторії [mihko-nush](https://github.com/neurolutionary/mihko-nush). Він перевіряє дані й зберігає окремий preview-пакет. GitHub Pages публікує статичні файли безпосередньо з гілки main.
- У **Settings → Pages → Build and deployment → Source** обрано **Deploy from a branch → main → / (root)**. Адреса 404 сама по собі не підтверджує стан цих налаштувань.
- Для приватного Mihko чинний тариф організації не підтримує Pages; для публікації створено окремий публічний mihko-nush із матеріалами цієї сторінки.
- Статична сторінка використовує лише `nush/index.html`, CSS, JS і `pilot.json`; корінь сайту веде на `nush/`. Ігрові файли та приватні зображення галереї не включено.
- Чинна збірка галереї також копіює `nush/`, щоб наступна ручна публікація повної галереї зберегла цей розділ. Самостійна публікація НУШ використовує інший репозиторій і не змінює сайт галереї.

Копія навчального каталогу зберігається в Mihko для майбутнього адаптера. При змінах карток слід оновлювати також публічну копію; автоматичну синхронізацію наразі не налаштовано.

## Освітня основа

Для пілоту обрано програму Савченко 2022 року, цикл 1–2 класів. Програми Савченко/Шияна, приклади безкоштовних PDF ІМЗО та матеріали видавців наведено в `pilot.json → sources` і на сторінці.

Нова програма, затверджена МОН 18.03.2026, починає застосовуватися для першокласників із 01.09.2028. Її потрібно додавати як окрему версію навчальної бази. Картки пілоту мають **тематичну прив’язку**, а не підтверджені офіційні коди результатів; `skillId` є внутрішнім ідентифікатором.

Підручник — орієнтир для послідовності тем. Перед розширенням слід обрати одну основну авторську лінійку для кожного предмета й циклу, звірити результат навчання, попередні знання та місце теми. Сторінки, малюнки й готове аудіо з підручників не переносимо без відповідного дозволу; готуємо власні матеріали.

## Одноразова інтеграція

| Компонент | Потрібна зміна |
| --- | --- |
| `neuro_start.gd` | Передавати `courseId`, показувати готовність кожного курсу |
| `game.gd` | Завантажувати маніфест/маршрут із реєстру замість одного JSON |
| `course_state.gd` | Прогрес, спроби, повторення і версія — окремо для кожного курсу; міграція дошкільного прогресу |
| `build_course.py`, `card_compiler.py` | Вхідний маніфест замість фіксованих наборів і кількостей; узгоджена версія схеми |
| `build_parent_catalog.py` | Звіт за курсом і навичкою замість фіксованої кількості 107 |

Рекомендовано зберігати `activeCourseId`, `progressByCourse[courseId]` і `activeAdventure.courseId`. Герой, ферма й колекція друзів спільні. Старі ID карток не змінювати. При зміні курсу не перевіряти старі completed-ID проти іншого маршруту; активну пригоду відновлювати в її власному курсі.

Окремий curriculum-каталог містить `subjectId`, `skillId`, передумови, тему/джерело програми та статус методичної перевірки. `game3d/data/catalog.json` є каталогом графіки; навчальні картки до нього не додаємо.

Пілот використовує `choose_one`, `choose_count` і `order`. Вебверсія реалізує вибір кнопками та послідовне натискання. Адаптер для гри має перетворити `answerIds` та варіанти у фактичний формат чинного експортера. Не підміняти JSON гри цим файлом.

## Приймання перед відкриттям 1 класу

1. Учитель звіряє правильність, мову, складність, передумови та результат навчання для кожної картки.
2. Підготовлено власні ілюстрації й голосові інструкції, особливо для дитини, яка ще не читає.
3. Експортер приймає пакет із новими ID, не порушуючи дошкільного маршруту.
4. На Android перевірено перше відкриття курсу, завершення/повторення, перезапуск, перемикання курсів і відновлення старого профілю.
5. Батьківський звіт правильно розрізняє курси, а кнопка 1 класу відкривається лише після готовності пакета.

Це пілот формату, не маршрут із 24 послідовних уроків: деякі картки потребують окремого попереднього навчання. Для наступних класів пишемо пакети за обраною послідовністю тем; відкриті письмові відповіді, диктант і усне мовлення потребуватимуть нових механік.

## Файли

- `index.html`, `styles.css`, `app.js`: сторінка, фільтри, вкладки, інтерактивна демонстрація.
- `pilot.json`: 24 картки, 5 рівнів, 4 напрями, джерела та метадані.
- Вміст і виконання відповідей не надсилаються на сервер. Ця демонстрація не зберігає дитячі профілі чи прогрес.
