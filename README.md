# НУШ у Mihko

Карта розвитку курсів 1–4 класів і 24 авторські картки пілоту 1 класу.

[Відкрити сторінку](https://neurolutionary.github.io/mihko-nush/nush/) · [План інтеграції та джерела](nush/README.md) · [Картки JSON](nush/pilot.json)

Авторський пілот 0.1, ще без методичного затвердження й підключення до Android-гри. У цьому репозиторії публікуються лише матеріали сторінки НУШ.

Публікація: GitHub Pages → Deploy from a branch → main → / (root). Кореневий index.html веде до nush/; .nojekyll вимикає обробку Jekyll. Workflow перевіряє дані й готує пакет для перегляду.
